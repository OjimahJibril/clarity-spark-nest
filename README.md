# SparkNest

A decentralized platform connecting startups with mentors and investors.

## Features
- Create startup profiles with funding goals and project details
- Milestone-based funding release system
- Mentor registration and verification system
- Investment tracking and management
- Reputation system for all participants
- Secure messaging between parties

## Architecture
The smart contract handles:
- Profile management for startups, mentors and investors
- Investment processing and tracking
- Milestone creation, completion, and approval
- Fund release based on milestone completion
- Reputation scoring
- Access control and permissions

## Milestone-Based Funding
The platform now supports milestone-based funding releases:
1. Startups can define milestones with specific funding requirements
2. When milestones are completed, startups mark them for review
3. Investors can approve completed milestones
4. Upon approval, funds are automatically released to the startup

This ensures:
- Better fund management
- Increased accountability
- Reduced investment risk
- Clear progress tracking
